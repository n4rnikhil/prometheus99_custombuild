2. ARCHITECTURE
--------------------------------------------------------------------------------
Fieldbus thread (1 kHz, THREAD_PRIORITY_TIME_CRITICAL, high-res waitable timer
with absolute deadlines - hal/timer.c hmi_pacer_*):
  heartbeat -> operator command bits -> driver poll (Modbus TCP state machine or
  simulator) -> 1 Hz trend -> ISA-18.2 evaluate -> supervise UI heartbeat ->
  drain UI audit-event ring -> CRC32-C of tag table -> seqlock publish.
UI thread (~30 Hz, MsgWaitForMultipleObjects):
  seqlock snapshot + CRC verify -> supervise fieldbus heartbeat -> RBAC
  auto-logout -> horn -> persistent log sync -> render bands -> StretchDIBits.
UI -> fieldbus: atomic command bits (InterlockedOr / InterlockedExchange) and a
  16-entry SPSC event ring for audit events. No mutexes anywhere.
Watchdogs: each loop supervises the other (500 ms). A trip latches failover and
  raises alarm point 13 "HMI watchdog failover" (CRITICAL) until Maintenance+
  resets it. Settings -> Test watchdog stalls the fieldbus thread 750 ms.

--------------------------------------------------------------------------------
4. KEY CONTRACTS
--------------------------------------------------------------------------------
- Tag ids: 0-7 PLC process, 8-11 host, 12 PLC comm loss, 13 HMI watchdog. Max 64.
- Values are scaled int16; meta.decimals says how to show them (842,1 -> "84.2").
- Manifest token: tag<<24 | type<<16 | x<<12 | y<<8 | w<<4 | h (16x16 grid over
  the content area; w/h 0 = 16). Widget types in include/renderer/bytecode.h.
  SCHNEIDER_MANIFEST_COUNT in driver_modbus.h must equal the table length
  (compile error otherwise).
- Modbus map: HR0..4 = level, rpm, valve(w), pressure, temp; coils 0..2 = pump A,
  pump B, E-stop. 0-based PDU addresses. Driver functions are called only from
  the fieldbus thread and never block.
- Alarm log line: seq,utc,uptime_ms,tag,SEV,STATE,"msg",crc where
  crc = CRC32-C(prev_crc_hex8 || line-before-last-comma); genesis 0xC001CAFE.
- Vault: 144 bytes "SECV" v1, 3 x {role, salt[8], sha256[32]}, CRC32-C.
  Factory PINs 1111/2222/3333 until `--set-pin`.

5. RULES FOR FUTURE CHANGES
--------------------------------------------------------------------------------
1. No malloc/calloc/realloc/free in application code.
2. Must stay clean under -Wall -Wextra -Wshadow -Werror and cppcheck
   (--enable=warning,performance,portability).
3. Never block the fieldbus loop; no mutexes between the loops.
4. Every new interactive element gets its rect from layout.c, and tests/test_core.c
   checks that its hit-test lands on it at several screen sizes.
5. Keep the portable modules free of OS headers (build.bat snapshot proves it).
6. The HMI E-STOP is a request to the PLC, never a safety function; never gate it
   behind RBAC or dialogs.
7. Measure, don't claim: update section 1 only with numbers from build/measure runs.
